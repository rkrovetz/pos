## Wikipedia Subset

All sentences were tagged using the spaCy `en_core_web_sm` model.

The Wikipedia subset used in the assessment is approximately:

- 2.1 GB uncompressed
- 632 MB compressed

Because of GitHub file size limits, the dataset is hosted externally.

Download it with:

    wget https://lexicalresearch.com/data/wikipedia_tagged_subset.tsv.gz
    gunzip wikipedia_tagged_subset.tsv.gz
